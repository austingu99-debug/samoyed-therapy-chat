# 🐾 動物心靈諮商室 (Animal Therapy Sanctuary)

一個融合**當代 10 大心理學流派**與**多種動物心靈夥伴**的療癒陪伴 AI 應用。採用溫暖奶油米色風格 UI，讓使用者在充滿同理心、無條件正向接納的空間中卸下疲憊與防備。

---

## 🎮 心靈療癒互動工具專區

1. 💬 **專屬心靈諮商室**：深度心理學同理心對話、情緒鏡映、情感合法化、一鍵心理話題引導晶片、自訂稱呼與暱稱。
2. 🌡️ **心靈情緒溫度計**：透過「命名情緒以馴服情緒（Name it to Tame it）」，點選委屈、疲憊、焦慮、自責等色票，立即獲得動物夥伴的心理學專屬承接反饋。
3. 🧸 **內在小孩擁抱室**：運用 IFS 與完形療法，引導使用者溫柔擁抱內心疲憊的小小孩，由動物夥伴守護與肯定。
4. 🌬️ **正念舒壓呼吸泡泡**：視覺化盒式呼吸光圈（Box Breathing），2 分鐘調節腹側迷走神經與心率。
5. 🔨 **煩惱粉碎機**：輸入壓力字句，由動物夥伴施展超萌動作（咬碎、貓爪抓爛、熊抱壓扁、刺刺戳破）化為星光與心理學金句。
6. 🥠 **心靈幸運籤**：敲開幸運餅乾，隨機領取深刻心理學名言與今日微小自我關懷任務。
7. 🧭 **5-4-3-2-1 焦慮著陸法**：經典抗焦慮五感覺察工具，迅速將大腦從胡思亂想拉回當下安全現實。

## 🚀 安裝與啟動

### 1. 安裝依賴
```bash
pip install -r requirements.txt
```

### 2. 設定 Groq API Key（免費）
在專案根目錄下建立 `.streamlit/secrets.toml`：
```toml
GROQ_API_KEY = "你的_GROQ_API_KEY"
```
*(亦可在啟動後的網頁介面直接輸入，無需手動改檔！)*

### 3. 啟動應用
```bash
streamlit run samoyed_therapy_app.py
```
瀏覽器開啟 `http://localhost:8501` 即可進入動物心靈諮商室！
